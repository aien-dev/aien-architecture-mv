# aien-architecture basics

This repository holds documents, not a product: the doctrine, the Architecture Decision Records (ADRs), the one active execution plan and the qualification records. The one program is the crumb tool in `tools/crumb` (C11 and `make`).

## Read first, in this order

1. `PLAN_AUTHORITY.md` (which document wins when two disagree)
2. `CURRENT_EXECUTION_PLAN.md` (the one active cross-project plan)
3. `doctrine/ARCHITECTURE.md`
4. `doctrine/ROADMAP.md`
5. the relevant accepted ADRs in `docs/adr/` (index: `docs/adr/README.md`)

## Build and test

```sh
make -C tools/crumb test
./tools/crumb/crumb verify .
```

The Spark judges every pull request with five gates. Each manifest in `tests/gates/` calls `tests/gates/run.sh` with one step word; run the same steps yourself with `bash` (plain `sh` stops at `set -o pipefail`):

```sh
bash tests/gates/run.sh crumb-verify          # CRUMB-VERIFY: crumbs are current
bash tests/gates/run.sh crumb-tool-test       # ARCH-CRUMB-TOOL-TEST
bash tests/gates/run.sh script-tests          # ARCH-SCRIPT-TESTS
bash tests/gates/run.sh doctrine              # ARCH-DOCTRINE: doctrine consistency
bash tests/gates/run.sh qualification-status  # ARCH-QUALIFICATION-STATUS (needs ../omega)
```

The agent hooks have their own test: `bash tools/agent-hooks/test.sh`.

## Invariants that must not move

- There is one active cross-project plan, `CURRENT_EXECUTION_PLAN.md`. Do not create another "master", "final", "complete" or "canonical" whole-system plan. Files under `docs/archive/plans/` are historical only.
- A milestone status changes only in `doctrine/ROADMAP.md`.
- Implementation and evidence truth beats planning claims. If code and a plan differ, record the discrepancy; never write a target as implemented.
- Nothing is described as qualified unless a receipt says so.
- Cite ADRs across repositories with a prefix: `ARCH-00nn` for this repository, `OS-00nn` for aienos.
- New substantive work follows `docs/process/ISSUE_FIRST_DELIVERY.md`.
- Current subsystem name is FORGE; historical `PHYSICS_*` milestone IDs and receipts stay unchanged.

## Where evidence lives

- Release candidates and their gate results: `qualification/candidates/` and `qualification/exceptions/`.
- Run receipts: in the repository that ran them, mostly omega `evidence/`, cited from `CURRENT_EXECUTION_PLAN.md` and `doctrine/ROADMAP.md`.
- Signed pull request verdicts from the Spark: the aien-receipts repository.

## Do not touch

- `.crumb` files and `crumb.lock`: generated by the crumb tool; do not hand-edit and do not run `crumb compile` unless the operator asks.
- `.aien/`, `tests/gates/`, `.github/workflows/`, `.forgejo/`, `tools/aien-test/`: pipeline configuration. A change there is BLOCKED_OPERATOR (ADR 0033, amendment 2026-10-11); the `protected-paths.sh` hook refuses it unless the operator sets `AIEN_PIPELINE_EDIT=1`.
- `tools/agent-hooks/` here is the canonical copy for the whole tree (ADR 0038): change it here first, run its `test.sh`, then recopy to the other repositories.

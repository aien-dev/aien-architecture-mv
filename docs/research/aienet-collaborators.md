## Purpose and project boundary

Find researchers and communities interested in humans and agents working together, agents acting under human authority, and open-source systems that preserve user control. Academic collaborators are a priority.

Potential collaboration topics include human-directed delegation, independent verification, cooperation between independent owners, authorization and revocation, reliable interruption/retry, and interpretable operator interfaces. These are suggested asks, not capabilities promised by the people listed.

Aienet has an exercised two-machine LAN prototype under one project operator. Independent-owner interoperability, public-network qualification, and independent security approval are not established. The demonstrated settlement used prefunded test credits, not publicly spendable currency. Describe current audit findings and repair status before offering any pilot. This directory does not supersede the execution plan, roadmap, or existing repository ownership.
